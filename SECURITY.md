# Security Policy

## Supported versions

Only the latest minor release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's vulnerability reporting](https://github.com/kongpda/laravel-attachments-core/security/advisories/new).

You will get an acknowledgement within a few days. Once a fix is released, the
advisory is published with credit to you, unless you ask to stay anonymous.
