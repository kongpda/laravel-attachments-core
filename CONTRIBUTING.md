# Contributing

Contributions are welcome through pull requests on
[GitHub](https://github.com/kongpda/laravel-attachments-core).

- Open an issue or discussion first for anything larger than a bug fix.
- Add or update tests for any change in behaviour.
- Keep one change per pull request.
- Document user-facing changes in `README.md` and under "Unreleased" in
  `CHANGELOG.md`.
- Report security issues privately, as described in [SECURITY.md](SECURITY.md).

Before you push, run:

```bash
composer test && composer analyse && composer format
```
